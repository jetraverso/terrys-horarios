Tocá un turno para marcarlo o quitarlo. Doble clic (o mantener apretado) para ajustar las horas o ver el fichaje y la foto. Tocá "festivo" debajo de un día para marcarlo.

Horario habitual

Marcá los turnos que cada uno hace normalmente cada semana. Después aplicalo al mes con un clic y ajustá a mano lo que cambie.

Un toque marca o quita el turno planificado. Los turnos ya fichados (✓) no se tocan desde acá: se editan en Semana.

Por hora: se paga la tarifa por cada hora del mes. Sueldo mensual: se paga el sueldo fijo y se muestra a cuánto sale la hora según lo trabajado. "Ajuste de horas" suma o resta horas (por ejemplo, -2 o 3,5). "Extra €" suma o resta un importe fijo (un adelanto en negativo, un plus en positivo). Todo se guarda solo.

Fichajes

Se muestran los turnos fichados desde la pantalla de fichaje. Tocá una foto para verla grande. "En curso" significa que fichó la entrada pero todavía no la salida.

Empleados

Ocho lugares. Los que no tienen nombre no aparecen en la grilla. El PIN es el que usan para fichar (dejalo vacío si no querés pedirlo).

Festivos

Las horas trabajadas en festivo se cuentan aparte en los totales.

Conexión con Supabase

Para usar la página fuera de claude.ai (en GitHub Pages, en el iPad del local, en tu celular) los datos y las fotos se guardan en un proyecto de Supabase tuyo. Las instrucciones están en el archivo README del repositorio.
